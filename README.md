# Туту: Угнать отпуск

Mobile-first браузерная мини-игра для тестирования в WebView: сбор вещей для отпуска, покупки, трафик, полиция после ДТП и вылет из аэропорта.

## Игра

После включения GitHub Pages: https://kirill54.github.io/tutu-ugnat-otpusk/

## Публикация

Settings -> Pages -> Build and deployment -> Source: GitHub Actions.

## Важно

Демонстрационные бонусы не начисляются на настоящий счёт. Для production WebView требуется дополнительное QA и серверная интеграция.
